# break_first example: exact list extents

A chat list of 10,000 messages. On the left, a stock `ListView`; on the right, the same list with item extents from
break-first. `flutter run --release` for the interactive version (jump, text size, check against TextPainter), or
`--dart-define=AUTOPLAY=true` for the scripted tour that `tool/record_android.sh` records.
